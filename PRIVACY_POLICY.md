# Privacy Policy

**Effective Date:** January 23, 2026  
**Last Updated:** January 23, 2026

## Overview

Architector-LLM is developed as part of academic research at the National University of Sciences and Technology (NUST), Pakistan. This privacy policy explains how we collect, use, and protect your data when you participate in our research study.

## Research Study

**Title:** "From Code to Architecture: Leveraging LLMs for Automated Software Design Documentation"  
**Researcher:** Engr. Hammad Khurshid  
**Institution:** NUST Pakistan  
**Contact:** engr.hammadkhurshid@gmail.com

## Voluntary Participation

Participation in data collection is **completely voluntary**. You can:
- Use the extension without participating in research
- Decline data collection at any time
- Withdraw consent and request data deletion
- Continue using all extension features regardless of participation

## What Data We Collect

### If You Consent to Research Participation:

**Developer Information (Provided by You):**
- Full name
- Email address
- Job title/designation
- Experience level (junior, mid, senior, etc.)
- Organization/company (optional)
- Country (optional)

**Usage Data (Automatically Collected):**
- Session ID (anonymous identifier)
- Timestamp of generation
- Extension and VS Code versions
- Operating system platform

**Project Metadata (Non-Sensitive):**
- Programming language detected
- Project type (e.g., Node.js, Python)
- Project size category (small/medium/large/enterprise)
- File count

**Performance Metrics:**
- Number of diagrams generated
- Generation time
- Success/failure status
- Quality scores
- Validation metrics (syntax, completeness, clarity, accuracy)

**Configuration Data:**
- LLM provider used (Ollama, DeepSeek, OpenAI, Claude)
- Model name

**Feature Usage:**
- Whether dependency check was run
- Whether About page was viewed
- Whether setup wizard was completed

## What We DON'T Collect

We explicitly **DO NOT** collect:
- ❌ Your source code or file contents
- ❌ File names or directory structures
- ❌ Project names or repository URLs
- ❌ API keys or credentials
- ❌ Proprietary or confidential information
- ❌ Personal conversations or messages
- ❌ IP addresses or precise location
- ❌ Browsing history or other application data

## How We Use Your Data

**Research Purposes Only:**
- Evaluate the effectiveness of LLM-based documentation generation
- Measure adoption rates and user satisfaction
- Analyze performance across different project types
- Identify areas for improvement
- Publish aggregated results in academic papers

**Academic Publication:**
Your data may be included in:
- Research papers and conference presentations
- Aggregated statistics (e.g., "85% success rate across 100 users")
- Anonymized examples (no identifiable information)

## Data Storage and Security

**Local Storage:**
- Analytics data is stored locally on your machine at:  
  `~/.vscode/extensions/architector.architector-llm-*/analytics/`
- Encrypted storage using VS Code Secrets API for API keys

**Remote Storage:**
- Data transmitted securely via HTTPS to NUST research servers
- Encrypted at rest using AES-256 encryption
- Access restricted to research team only
- No third-party access or sharing

**Retention Period:**
- Data retained for duration of research study (approximately 2 years)
- After study completion, data archived or anonymized
- Original data deleted 5 years after study completion (per academic standards)
