## Problem Identified

Your test report revealed that **v2.0.8 was completely broken** due to tree-sitter version incompatibility:

```
TypeError: set_language() argument must tree_sitter.Language, not PyCapsule
```

**Root Cause:**
- tree-sitter 0.22.3 (core) was incompatible with tree-sitter-* 0.23.x (language modules)
- The 0.23.x modules return `PyCapsule` objects
- tree-sitter 0.22.3 couldn't process PyCapsule objects

---

## Solution Applied

### 1. Upgraded tree-sitter Core ✅

**Before:** tree-sitter==0.22.3  
**After:** tree-sitter==0.23.2

### 2. Updated Parser Code ✅

Changed from `set_language()` pattern to `Language()` wrapper:

**Before (v2.0.8):**
```python
python_parser = Parser()
python_parser.set_language(tspython.language())  # ❌ Fails
```

**After (v2.0.9):**
```python
from tree_sitter import Language, Parser

python_parser = Parser(Language(tspython.language()))  # ✅ Works
```

### 3. Pinned Compatible Versions ✅

All language modules set to 0.23.2 for consistency:

```
tree-sitter==0.23.2

tree-sitter-javascript==0.23.1
```
