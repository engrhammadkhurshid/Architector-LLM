## 🚨 Critical Fix: tree-sitter Dependency Compatibility

### Issue Resolved

**v2.0.8 Problem:**
- Extension crashed immediately on activation
- TypeError: `set_language() argument must tree_sitter.Language, not PyCapsule`
- All functionality broken

**Root Cause:**
- tree-sitter 0.22.3 (core) incompatible with tree-sitter-* 0.23.x (language modules)
- 0.23.x modules return `PyCapsule` objects, but 0.22.3 expects `Language` objects
- API breaking change between 0.21.x → 0.23.x

**v2.0.9 Solution:**
- ✅ Upgraded tree-sitter from 0.22.3 to 0.23.2
- ✅ Updated parser code to use Language() wrapper for PyCapsule
- ✅ Pinned all language parsers to 0.23.2 for version compatibility
- ✅ Extension fully functional

## Developer Notes

### Why 0.21.0 Instead of Latest?

**Question:** Why not upgrade tree-sitter to 0.23.x?

**Answer:**
- tree-sitter 0.23.x has breaking API changes
- Would require rewriting parser initialization code
- 0.21.0 versions are stable and proven
- All features work correctly with 0.21.0

**Future Consideration:**
- May upgrade to 0.23.x in v2.1.0 or v3.0.0
- Will require thorough testing
- Benefits unclear vs. risks
